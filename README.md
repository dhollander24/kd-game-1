# KD Game 1

A live two-player game of words, walls and TNT.

- `index.html` is the whole game. Edit it here and the site updates.
- `words.js` is the dictionary.
- `build.py` is only needed to update the copy on Claude.

The balance settings (costs, health, bonuses) are near the top of the script in `index.html`, under `constants`.
